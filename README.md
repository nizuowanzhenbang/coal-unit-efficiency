# ⚡ 燃煤机组能效与智能燃烧优化系统

> 一台 600MW 燃煤机组，供电煤耗每多 1 克/千瓦时，一年就要多烧约 1500 吨标煤、多花 130 多万元、多排 4000 吨二氧化碳。可这"1 克"藏在排烟温度、氧量、飞灰含碳量、真空度几十个表计的细微偏差里，靠人盯表根本算不清。

本系统把电厂运行人员最关心的那个总分——**供电煤耗**——拆解到每一个可调参数上：用锅炉反平衡法实时算出"热都跑到哪去了"，用耗差分析把每个指标的偏差翻译成"多烧了多少煤"，再用 AI 燃烧寻优给出"氧量调到多少、磨怎么配"的具体动作，最后用一块驾驶舱大屏把整个机组群的能效家底一目了然地摆出来。

> **边界说明**：本系统是能效分析与决策辅助平台，运行参数来自 DCS/SIS 采集或人工录入。所有优化建议为参考性指导，实际运行调整须经运行规程与值长确认；本仓库为代码资产交付，演示数据为模拟生成。

## 核心能力

### 🔥 反平衡能效画像：热都跑哪去了

正平衡要精确计量入炉煤，现场误差大；本系统用**反平衡法**（GB 10184 / DL/T 904），只靠烟气、灰渣等参数，把锅炉的五项热损失逐项算清：

> 排烟热损失 q2（烟气从烟囱带走的热）· 化学不完全燃烧 q3 · 机械不完全燃烧 q4（灰里没烧尽的碳）· 散热损失 q5 · 灰渣物理热损失 q6 —— **锅炉效率 = 100% − 五项损失之和**

再叠加管道效率、汽机循环效率，反算出**发电煤耗、供电煤耗、机组热耗率、厂用电率**整套能效指标，每条工况进来都生成一张完整的能效快照。

### 📉 耗差分析：把"偏差"翻译成"多烧的煤"

"排烟温度高了 8℃"到底意味着什么？耗差分析用灵敏度系数把每个小指标的偏差直接折算成**供电煤耗影响（g/kWh）**，并按影响大小排序——运行调整从此有的放矢，不再凭感觉。

> 排烟温度、氧量、飞灰含碳量、主/再热汽温、凝汽器真空、厂用电率……每一项都标出"朝坏的方向偏了多少、折合多烧几克煤"，并用瀑布图把账摊开。

### 🤖 AI 燃烧寻优：把白烧的煤捡回来

针对当前负荷与煤质，给出能把煤耗压到最低的运行动作。采用**数据驱动 + 机理先验**双保险：历史样本充足时用多元线性回归拟合"煤耗 = f(负荷, 氧量, 排烟温度, 飞灰含碳量)"实时寻优；样本不足时退回机理先验（最优氧量随负荷升高而降低）。输出**建议氧量、二次风配比、磨煤机组合、预期降煤耗、折合日省金额、置信度**，并支持专工"采纳/驳回"留痕。

### 🖥️ 能效驾驶舱：全厂能效一屏掌控

机组群实时能效大屏：每台机组的供电煤耗仪表盘（按偏离设计值变色）、实际 vs 设计对比、锅炉效率/厂用电率、未关闭预警数、**已采纳建议累计日省金额**——为生产例会和对外汇报提供"看得见的成果"。

### 🔁 闭环告警与跨系统联动

供电煤耗超设计目标、锅炉效率掉档、耗差合计越限，自动生成预警并走"触发→确认→关闭"闭环（同类未关闭告警自动去重，杜绝告警风暴）。严重能耗事件可推送至**安全生产系统**备案，锅炉效率异常可推送至**设备点检系统**生成排查工单。

### 📈 能效报告与节煤减碳量化

一键生成能效日报/月报：周期平均煤耗、对标偏差、主要耗差项 TOP5，并自动测算**较目标节约的标煤量、节约金额、减碳量**——节能降碳的成绩有账可查、可签发归档。

## 快速启动

```bash
docker compose up --build
# 前端 http://localhost:5182   ·   后端 API http://localhost:8012/docs
```

容器启动时自动建库并注入演示数据（`CUE_AUTO_SEED=true`）。本地开发可在 `backend/` 内 `uvicorn app.main:app --port 8012`，`frontend/` 内 `npm run dev`。

> **能效算法小科普**：为什么供电煤耗的理论极限是约 122.84 g/kWh？因为 1 度电 = 3600 kJ，而 1 kg 标准煤 = 29307 kJ，全部转成电只需 3600/29307 ≈ 0.12284 kg。真实煤耗 = 122.84 ÷ 机组总效率，所以提效率就是降煤耗，这也是本系统所有功能的共同落脚点。
